# PyMessenger

Учебный веб-мессенджер на Python, Flask и SQLite с тёмным интерфейсом.

## Что есть в проекте
- Создание аккаунта и вход по номеру телефона и паролю.
- Хеширование паролей; пароль не хранится открытым текстом.
- Личные и групповые чаты.
- История сообщений в SQLite.
- Отправка текста, изображений и поддерживаемых файлов до 25 МБ.
- Голосовые сообщения через микрофон браузера (нужен localhost или HTTPS).
- Голосовые и видеозвонки в личных чатах через WebRTC; нужны разрешения микрофона/камеры и HTTPS.
- Для устойчивых звонков между разными сетями настрой TURN-сервер через `PYMESSENGER_TURN_URL`, `PYMESSENGER_TURN_USERNAME` и `PYMESSENGER_TURN_CREDENTIAL`.
- Профиль с именем, описанием и аватаром.
- Встроенный интерфейс Gloria AI (нужен API-ключ OpenAI или совместимого API).
- Встроенный Spotify Embed для треков, альбомов и плейлистов.
- Опциональное шифрование текста новых сообщений в базе данных через Fernet.
- Автоматические тесты для основных API и входа.

## Запуск в Windows
1. Установи Python 3.10 или новее.
2. Открой папку проекта в терминале.
3. Создай виртуальное окружение:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
4. Установи зависимости:
   ```powershell
   py -m pip install -r requirements.txt
   ```
5. Запусти сервер:
   ```powershell
   py app.py
   ```
6. Открой http://127.0.0.1:5000.
7. Для нового аккаунта введи номер, имя и пароль длиной не менее 6 символов. Для следующих входов используй те же номер и пароль.

## Доступ с телефона
В одной Wi-Fi сети открой на телефоне адрес компьютера, например `http://192.168.1.25:5000`. Точный адрес компьютера смотри командой `ipconfig` в Windows. Разреши входящие подключения Python в брандмауэре. Для работы из любой сети нужно развернуть сервер в интернете и настроить HTTPS.

## Настройка публичного сервера
Установи переменную окружения `PYMESSENGER_SECRET` в длинное случайное значение и включи HTTPS. Установи `COOKIE_SECURE=1` только после настройки HTTPS. Используй постоянное хранилище для папок `instance/` и `uploads/`; без него история и загруженные файлы могут пропасть после перезапуска хостинга.

Пример запуска за production-сервером:
```bash
gunicorn app:app
```

## Звонки
В личном чате нажми значок телефона для голосового звонка или значок экрана для видеозвонка. Входящий вызов нужно принять. Браузер попросит разрешение на микрофон/камеру; для публичного сайта необходим HTTPS. По умолчанию используется STUN, который помогает установить прямое соединение, но не гарантирует связь за каждой корпоративной сетью или NAT. Для большей надёжности настрой TURN-сервис через три переменные окружения выше. Звонки проверяются автоматическими тестами сигнализации, но реальный аудио/видеозвонок между устройствами требует отдельной ручной проверки.

## Gloria AI и Spotify
- В Render добавь переменную `OPENAI_API_KEY` с ключом API-провайдера. По умолчанию используется модель `gpt-4o-mini`; при необходимости можно задать `OPENAI_MODEL` и совместимый `OPENAI_BASE_URL`.
- Spotify работает через официальный встроенный плеер. Для некоторых треков может понадобиться войти в Spotify.

## Шифрование сообщений
Для шифрования текста новых сообщений в базе установи переменную окружения `PYMESSENGER_ENCRYPTION_KEY`. Сгенерировать ключ локально после установки зависимостей:
```powershell
py -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
Скопируй полученную строку в переменные окружения Render и сохрани её в надёжном месте. **Не меняй и не теряй ключ:** без прежнего ключа зашифрованные сообщения нельзя будет прочитать. Уже сохранённые ранее сообщения автоматически не шифруются. Это шифрование базы на сервере, а не сквозное шифрование (E2EE): сервер всё ещё может видеть текст после расшифровки. Для настоящего E2EE нужна отдельная система обмена ключами между устройствами.

Это прототип, не готовый защищённый сервис для конфиденциальной переписки. В нём нет сквозного шифрования, восстановления пароля, защиты от спама и полноценной модерации. Для публичного сервиса дополнительно нужны HTTPS, резервные копии, ограничение частоты запросов и усиленная проверка загружаемых файлов. Сборка Android APK — отдельная часть проекта и сама по себе не размещает сервер в интернете.
