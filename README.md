# PyMessenger Pro

Учебный веб-мессенджер на Python/Flask с тёмным интерфейсом в стиле современных чат-приложений.

## Функции
- Регистрация и вход по логину/паролю (пароли хешируются Werkzeug).
- Профиль: отображаемое имя, описание, аватарка.
- Личные чаты и групповые чаты.
- История переписки в SQLite.
- Отправка изображений и файлов до 25 МБ.
- Запись и отправка голосовых сообщений из браузера (нужен localhost или HTTPS).
- Обновление сообщений каждые ~1.8 секунды.
- Поиск пользователей и чатов.
- Responsive UI для компьютера и мобильного браузера.

## Требования
- Python 3.10+
- Современный браузер
- Для голосовых сообщений на удалённом сайте нужен HTTPS.

## Запуск в Windows
1. Установи Python с https://www.python.org/downloads/ (при установке отметь **Add Python to PATH**).
2. Распакуй архив и открой папку `PyMessenger_Pro`.
3. Открой PowerShell/терминал в этой папке.
4. Создай виртуальное окружение (необязательно, но рекомендуется):
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
5. Установи зависимости:
   ```powershell
   py -m pip install -r requirements.txt
   ```
6. Запусти сервер:
   ```powershell
   py app.py
   ```
7. Открой в браузере http://127.0.0.1:5000 и создай аккаунт.
8. Чтобы проверить чат, открой второй браузер или окно инкогнито и зарегистрируй второй аккаунт. Найди его через кнопку `+`.

На Linux/macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

## Как пользоваться
- Кнопка `+` в левой панели — найти пользователя и открыть личный чат.
- `+ группа` — создать групповой чат и добавить участников.
- Скрепка/плюс рядом с полем ввода — выбрать фото или файл.
- Микрофон — начать запись; кнопка меняется на квадрат для остановки и отправки.
- Нажми на аватар/шестерёнку, чтобы изменить имя, описание и аватарку.

## Доступ по локальной сети
На компьютере-сервере выполни `ipconfig` и узнай IPv4-адрес, например `192.168.1.25`. На другом устройстве в той же сети открой:
`http://192.168.1.25:5000`
Разреши Python в брандмауэре, если Windows спросит. Это всё ещё локальная сеть, не публичный интернет.

## Размещение в интернете
Чтобы люди могли подключаться из разных сетей, разверни приложение на Python-хостинге, который поддерживает Flask, например Render, Railway или VPS:
1. Загрузи проект в собственный GitHub-репозиторий.
2. Создай Web Service из этого репозитория.
3. Команда сборки: `pip install -r requirements.txt`
4. Команда запуска: `gunicorn app:app`
5. Установи переменную окружения `PYMESSENGER_SECRET` в длинное случайное значение.
6. Включи HTTPS и выставь `COOKIE_SECURE=1` только когда HTTPS уже работает.
7. Для постоянной работы обязательно подключи постоянный диск/том для `pymessenger.db` и `uploads/`. Без постоянного диска файлы и история могут исчезнуть при пересборке/перезапуске хостинга. В этом starter-проекте путь к базе фиксирован рядом с `app.py`, поэтому на хостинге с отдельным persistent volume настрой путь перед публикацией или используй VPS.
8. Убедись, что лимиты загрузки, резервные копии и политика хранения подходят твоему использованию.

## Важные ограничения безопасности
Это рабочий стартовый проект, но не готовый сервис для чувствительных переписок:
- Нет сквозного шифрования (E2EE), восстановления пароля, подтверждения email, ограничения частоты запросов и полноценной модерации.
- SQLite подходит для прототипа; для крупного публичного сервиса лучше PostgreSQL.
- Загружаемые файлы ограничены расширениями и размером, но перед публичным запуском добавь антивирусную проверку и более строгую валидацию MIME/содержимого.
- Не используй стандартный `PYMESSENGER_SECRET` на публичном сервере.
- Не запускай с `debug=True` на публичном сервере.
- Голосовые сообщения используют возможности браузера; микрофон обычно доступен только на localhost или HTTPS.
